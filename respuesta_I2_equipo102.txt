a: Se debe vincular el repositorio original agregandolo como remoto "upstream" con el comando:
git remote add upstream <URL_REPO_ORIGINAL>
Luego se descargan y fusionan los cambios ejecutando:
git fetch upstream
git merge upstream/main
Y finalmente se sube la actualizacion al fork propio con:
git push origin main
